 - *字符串*
 
字符串类型的数据变量  用单引号和双引号都可以 如果要保留单引号或者双引号 应该怎么做呢  用转义字符/  

原始字符串还有一个微妙的限制：一个原始字符串不能以奇数个 \ 字符结束

字符串的索引  索引的数值可以是负数 这一点区别于c语言

相同类型的文本可以自动实现联合 用+或者*实现重复

还可以实现字符串的索引与切片 他的下标可以有负数 正数  **注意负数开始索引时从倒数开始数**  

切片时的注意事项 用方括号和冒号分隔开

 - *列表* 

列表的定义是什么  用方括号和逗号相隔  一般里面的数据都是同一种类型的 亦可以是不同类型的

列表同样支持切片和索引还有合并操作  合并用的是+号 那么列表可以使用*实现重复吗

 **当你将一个列表赋值给一个变量时，该变量将引用 现有的列表。你通过一个变量对列表所做的任何更改都会被引用它的所有其他变量看到**

如何清空列表元素 用[]直接清空 改变列表中的元素 可以改变切片中里面的数据来改变列表中的元素
###  代码的展示
```
letters = ['a', 'b', 'c', 'd', 'e', 'f', 'g']
letters

# 替换一些值
letters[2:5] = ['C', 'D', 'E']
letters

# 现在移除它们
letters[2:5] = []
letters

# 通过用一个空列表替代所有元素来清空列表
letters[:] = []
letters

rgb = ["Red", "Green", "Blue"]
rgba = rgb
id(rgb) == id(rgba)  # 它们指向同一个对象

rgba.append("Alph")
rgb


```
