# 数据集

这个文件夹放各个练习用到的原始数据，统一放在这里，练习脚本只读不改。

数据文件不进 Git（`.gitignore` 里忽略了 `*.csv`），换电脑时按下面的来源重新下载就行。

| 文件 | 用在哪里 | 来源 |
| --- | --- | --- |
| `melb_data.csv` | `machine_learning/01_data_exploration.py` | Kaggle 数据集 Melbourne Housing Market（Intro to Machine Learning 第 1 课） |

下载地址：<https://www.kaggle.com/datasets/anthonypino/melbourne-housing-market>

Kaggle 页面右侧 Download → 解压得到 `melb_data.csv` → 放到本文件夹。
